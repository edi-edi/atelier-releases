# Atelier releases

Signed downloads of Atelier are attached to this repository's
[Releases](https://github.com/edi-edi/atelier-releases/releases). The `gh-pages` branch
serves the download page (https://edi-edi.github.io/atelier-releases/), the Terminal installer
(https://edi-edi.github.io/atelier-releases/install.sh) and the Sparkle update feed (https://edi-edi.github.io/atelier-releases/appcast.xml).
Each release refreshes these files.
